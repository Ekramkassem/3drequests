# 3D Requests — Premium 3D Design Studio

A high-performance, dark-aesthetic 3D design studio platform built with React 19, Three.js, GSAP ScrollTrigger, and Tailwind CSS. Features an interactive WebGL spatial showroom, a master archive of 217 real client commissions across 9 disciplines, and an engineering-grade custom design request configurator.

## Features

- **Continuous 3D Spatial Showroom**: Tactile WebGL 3D card stack powered by Three.js and GSAP momentum drag physics with zero-allocation render loops.
- **Master Archive of 217 Commissions**: Full catalog covering Product Design, Characters & Anatomy, Industrial CAD, Game Assets & Weapons, Additive 3D Prototyping, Motion CGI, Architecture & Spatial BIM.
- **Deep Technical Case Studies**: Inspect polycounts, topology flows, materials, 8K CMF specifications, and target engine compatibility.
- **Interactive Design Request Suite**: Direct creative briefing workflow with automated budget estimating and parameter scoping.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- npm

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Ekramkassem/3drequests.git
   cd 3drequests
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- **Framework**: React 19, TypeScript, Vite 8
- **3D & Animation**: Three.js, GSAP 3 (ScrollTrigger, Draggable), Framer Motion
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
